# Kriol of Bolama dictionary

**Language:** Kriol of Bolama  
**Region:** Bolama  
**Administrative unit:** Região de Bolama-Bijagós  
**ISO 639-3:** pov  
**Translation pairs:** Kriol of Bolama → Portuguese; Kriol of Bolama → English
**Project started:** 23 March 2023  

This file is a **Bolama-only** Guinea-Bissau Kriol dataset. It is not a website and not an application.

Do not copy headwords from other Guinea-Bissau region folders (bissau, biombo, cacheu, oio, bafata, gabu, quinara, tombali).
Do not copy Cabo Verdean Kabuverdianu, Casamance Kriyol, Forro, Angolar, or Lung’Ie.

No lexicon has been copied from other folders. Add a headword only when a cited source labels it as the Kriol of Bolama.
