# Kriol of Quinara dictionary

**Project started:** 23 March 2023  

This file is a **Quinara-only** Guinea-Bissau Kriol dataset. It is not a website and not an application.

Do not copy headwords from other Guinea-Bissau region folders (bissau, biombo, cacheu, oio, bafata, gabu, tombali, bolama).
Do not copy Cabo Verdean Kabuverdianu, Casamance Kriyol, Forro, Angolar, or Lung’Ie.

No lexicon has been copied from other folders. Add a headword only when a cited source labels it as the Kriol of Quinara.
