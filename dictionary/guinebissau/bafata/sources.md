# Kriol of Bafatá sources

This dataset documents **Kriol of Bafatá** only (Região de Bafatá).

Translation pairs: Kriol of Bafatá → Portuguese, Kriol of Bafatá → English.

Do not fill missing entries from other Guinea-Bissau region folders.
Do not treat Cabo Verdean Kabuverdianu or Casamance Kriyol as this variety.

## Sources used in this folder

None yet. Add attested forms only from sources that name the Bafatá variety or this region.

APiCS Online language 33 is country-level Guinea-Bissau Kriyol. It is not labelled as this region and is not used here. See `dictionary/guinebissau/sources.md`.

Priority sources to search when collecting (do not invent forms from this list):

- APiCS Online, when the example is labelled as Kriol of Bafatá / this region
- Published Kriol dictionaries and grammars that locate the form in Bafatá
- Institutional orthography documents, only when they give a lemma labelled for Bafatá

## Not used as Bafatá evidence

- Other folders under `dictionary/guinebissau/`
- `dictionary/caboverde/`
- Casamance Kriyol of Senegal
- `dictionary/saotome/forro/`, `dictionary/saotome/angolar/`, `dictionary/saotome/lungie/`
- Portuguese of Guinea-Bissau
