# Angola creole sources

This folder is an **alias**. It does not hold its own word list.

The principal Angola-related creole in this repository is **Angolar / Ngola**. All sources and entries are in `dictionary/saotome/angolar/sources.md` and `dictionary/saotome/angolar/dictionary.json`.

Angolar collection belongs to the São Tomé work that started on **23 March 2023**. This alias folder is in use from **23 April 2025** (**2 years 1 month** later). Do not extract a parallel Angola lexicon here.

APiCS Online language 36 (Maurer 2013, Angolar) is already extracted in `dictionary/saotome/angolar/`. Do not copy it into this folder.

Kimbundu, Umbundu, and Angolan Portuguese are not Angolar headwords.
