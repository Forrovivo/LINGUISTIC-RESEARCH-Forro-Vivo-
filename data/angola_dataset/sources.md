# Angola sources

This parent folder is an **index of Angola languages**. It does not hold a merged word list.

It is **not** Angolar / Ngola. Angolar / Ngola is a São Tomé creole. Its sources and entries stay in `data/saotome_dataset/angolar/sources.md` and `data/saotome_dataset/angolar/dictionary.json`. Do not copy them here.

Angola collection starts on **23 April 2025** (**2 years 1 month** after the project start of **23 March 2023**).

Each language is isolated:

- `contruy/` — Angola Contruy
- `umbundu/` — Umbundu (`umb`)
- `kimbundu/` — Kimbundu (`kmb`)
- `kikongo/` — Kikongo (`kng`)

Do not copy between these folders. APiCS Online language 36 (Maurer 2013, Angolar) is not Angola evidence.

Kikongo of Angola is not Kituba. Angolan Portuguese is not stored as Contruy, Umbundu, Kimbundu, or Kikongo.

## Missing-term protocol

Query a named language folder. Use that folder’s `TERM_NOT_FOUND` object. Do not fall back to Angolar, Forro, Lung’Ie, Cabo Verdean, Guinea-Bissau Kriol, or another Angola language.
