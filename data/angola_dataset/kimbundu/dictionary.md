# Kimbundu dictionary

**Language:** Kimbundu  
**Country:** Angola  
**ISO 639-3:** kmb  
**Translation pairs:** Kimbundu → Portuguese; Kimbundu → English  
**Project started:** 23 March 2023  
**Collection started:** 23 April 2025  

This file is a **Kimbundu** dataset. It is not Umbundu, not Kikongo, and not Angola Contruy.

Do not copy headwords from `umbundu/`, `kikongo/`, or `contruy/`. Do not copy Angolar, Forro, Lung’Ie, Cabo Verdean, or Guinea-Bissau vocabulary.

No lexicon has been copied from other folders. Add a headword only when a cited source labels it as Kimbundu.

If a requested Kimbundu term is not in this dataset:

{"status": "error", "code": "TERM_NOT_FOUND", "message": "Translation not available in the verified Kimbundu database."}
