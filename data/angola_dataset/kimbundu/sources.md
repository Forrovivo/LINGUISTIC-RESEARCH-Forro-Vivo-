# Kimbundu sources

This dataset documents **Kimbundu** only (`kmb`).

Translation pairs: Kimbundu → Portuguese, Kimbundu → English.

Do not fill missing entries from Umbundu, Kikongo, Angola Contruy, or other folders in this repository.

## Sources used in this folder

None yet. Add attested forms only from sources that name Kimbundu.

Priority sources to search when collecting (do not invent forms from this list):

- Published Kimbundu dictionaries and grammars
- Academic papers that label the form as Kimbundu
- Institutional orthography documents, only when they give a lemma labelled Kimbundu

## Not used as Kimbundu evidence

- Other folders under `data/angola_dataset/`
- `data/saotome_dataset/forro/`, `data/saotome_dataset/angolar/`, `data/saotome_dataset/lungie/`
- `data/caboverde_dataset/`
- `data/guinebissau_dataset/`
- Angolan Portuguese
- APiCS 36 (Angolar)
