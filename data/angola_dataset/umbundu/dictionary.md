# Umbundu dictionary

**Language:** Umbundu  
**Country:** Angola  
**ISO 639-3:** umb  
**Translation pairs:** Umbundu → Portuguese; Umbundu → English  
**Project started:** 23 March 2023  
**Collection started:** 23 April 2025  

This file is an **Umbundu** dataset. It is not Kimbundu, not Kikongo, and not Angola Contruy.

Do not copy headwords from `kimbundu/`, `kikongo/`, or `contruy/`. Do not copy Angolar, Forro, Lung’Ie, Cabo Verdean, or Guinea-Bissau vocabulary.

No lexicon has been copied from other folders. Add a headword only when a cited source labels it as Umbundu.

If a requested Umbundu term is not in this dataset:

```json
{"status": "error", "code": "TERM_NOT_FOUND", "message": "Translation not available in the verified Umbundu database."}
```
