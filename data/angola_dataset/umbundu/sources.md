# Umbundu sources

This dataset documents **Umbundu** only (`umb`).

Translation pairs: Umbundu → Portuguese, Umbundu → English.

Do not fill missing entries from Kimbundu, Kikongo, Angola Contruy, or other folders in this repository.

## Sources used in this folder

None yet. Add attested forms only from sources that name Umbundu.

Priority sources to search when collecting (do not invent forms from this list):

- Published Umbundu dictionaries and grammars
- Academic papers that label the form as Umbundu
- Institutional orthography documents, only when they give a lemma labelled Umbundu

## Not used as Umbundu evidence

- Other folders under `data/angola_dataset/`
- `data/saotome_dataset/forro/`, `data/saotome_dataset/angolar/`, `data/saotome_dataset/lungie/`
- `data/caboverde_dataset/`
- `data/guinebissau_dataset/`
- Angolan Portuguese
- APiCS 36 (Angolar)
