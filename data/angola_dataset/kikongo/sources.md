# Kikongo sources

This dataset documents **Kikongo of Angola** only (`kng`).

Translation pairs: Kikongo → Portuguese, Kikongo → English.

Do not fill missing entries from Umbundu, Kimbundu, Angola Contruy, Kituba, or other folders in this repository. Kikongo is not Kituba (`ktu`).

## Sources used in this folder

None yet. Add attested forms only from sources that name Kikongo of Angola.

Priority sources to search when collecting (do not invent forms from this list):

- Published Kikongo dictionaries and grammars that locate the form in Angola
- Academic papers that label the form as Kikongo of Angola
- Institutional orthography documents, only when they give a lemma labelled Kikongo of Angola

## Not used as Kikongo of Angola evidence

- Other folders under `data/angola_dataset/`
- Kituba (`ktu`)
- `data/saotome_dataset/forro/`, `data/saotome_dataset/angolar/`, `data/saotome_dataset/lungie/`
- `data/caboverde_dataset/`
- `data/guinebissau_dataset/`
- Angolan Portuguese
- APiCS 36 (Angolar)
