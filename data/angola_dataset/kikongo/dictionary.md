# Kikongo dictionary

**Language:** Kikongo  
**Country:** Angola  
**ISO 639-3:** kng  
**Translation pairs:** Kikongo → Portuguese; Kikongo → English  
**Project started:** 23 March 2023  
**Collection started:** 23 April 2025  

This file is a **Kikongo of Angola** dataset. It is not Umbundu, not Kimbundu, not Angola Contruy, and **not Kituba**.

Do not copy headwords from `umbundu/`, `kimbundu/`, or `contruy/`. Do not copy Angolar, Forro, Lung’Ie, Cabo Verdean, or Guinea-Bissau vocabulary.

No lexicon has been copied from other folders. Add a headword only when a cited source labels it as Kikongo of Angola.

If a requested Kikongo term is not in this dataset:

```json
{"status": "error", "code": "TERM_NOT_FOUND", "message": "Translation not available in the verified Kikongo database."}
```
