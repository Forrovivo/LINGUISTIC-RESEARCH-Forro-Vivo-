# Cameroonian Pidgin sources

This dataset documents **Cameroonian Pidgin** only.

Cameroonian Pidgin collection starts on **20 August 2026** (**3 years 4 months 28 days** after the project start of **23 March 2023**). The lexicon stays empty until a cited source names Cameroonian Pidgin.

Do not copy Naija, Krio, Ghanaian Pidgin, or Pichi.

## Sources used in this folder

None yet. Add attested forms only from sources that name Cameroonian Pidgin.

## Not used as Cameroonian Pidgin evidence

- Other folders under `data/cameroon_dataset/`
- Other country folders in `data/`
- Portuguese, English, or French of Cameroon unless a source labels the form as Cameroonian Pidgin

## Missing-term protocol

Use this folder’s `TERM_NOT_FOUND` object. Do not fall back to another language in this repository.
