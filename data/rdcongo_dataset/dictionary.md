# Democratic Republic of the Congo

**Country:** Democratic Republic of the Congo  
**Project started:** 23 March 2023  
**Collection started:** 20 August 2026  
**Time since project start:** 3 years 4 months 28 days  

Democratic Republic of the Congo is not one lexicon in this repository. Each language has its own folder.

This parent folder is an **index**, not a merged dictionary.

## Languages

| Language | ISO | Path |
|---|---|---|
| Kituba | `ktu` | [kituba/](kituba/) |

Each language folder has `dictionary.md`, `dictionary.json`, and `sources.md`. Lexicons stay empty until a source names that language.

Do not store a merged Congo lexicon here. Kituba is a separate dataset under this folder. Kikongo of Angola stays in data/angola_dataset/kikongo/. They are not the same language.

If a term is not attested for that language, return `TERM_NOT_FOUND` for that language only.
