# Kituba sources

This dataset documents **Kituba** only.

Kituba collection starts on **20 August 2026** (**3 years 4 months 28 days** after the project start of **23 March 2023**). The lexicon stays empty until a cited source names Kituba.

Do not copy Kikongo of Angola, Umbundu, Kimbundu, Fanakalo, or Lingala unless a cited source labels the form as Kituba.

## Sources used in this folder

None yet. Add attested forms only from sources that name Kituba.

## Not used as Kituba evidence

- Other folders under `data/rdcongo_dataset/`
- Other country folders in `data/`
- Portuguese, English, or French of Democratic Republic of the Congo unless a source labels the form as Kituba

## Missing-term protocol

Use this folder’s `TERM_NOT_FOUND` object. Do not fall back to another language in this repository.
