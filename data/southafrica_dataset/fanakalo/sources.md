# Fanakalo sources

This dataset documents **Fanakalo** only.

Fanakalo collection starts on **20 August 2026** (**3 years 4 months 28 days** after the project start of **23 March 2023**). The lexicon stays empty until a cited source names Fanakalo.

Do not copy Kituba, Kikongo of Angola, Naija, Krio, or South African English.

## Sources used in this folder

None yet. Add attested forms only from sources that name Fanakalo.

## Not used as Fanakalo evidence

- Other folders under `data/southafrica_dataset/`
- Other country folders in `data/`
- Portuguese, English, or French of South Africa unless a source labels the form as Fanakalo

## Missing-term protocol

Use this folder’s `TERM_NOT_FOUND` object. Do not fall back to another language in this repository.
