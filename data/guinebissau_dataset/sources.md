# Guinea-Bissau Kriol sources

This parent folder is an **index of regional varieties**. It does not hold a merged Kriol word list.

ISO 639-3 for the language cluster: **pov**.

Collection of these region folders starts on **23 April 2025**, which is **2 years 1 month** after the project start of **23 March 2023**.

Each region is isolated:

- `bissau/` — Bissau (setor autónomo)
- `biombo/` — Biombo
- `cacheu/` — Cacheu
- `oio/` — Oio
- `bafata/` — Bafatá
- `gabu/` — Gabú
- `quinara/` — Quinara
- `tombali/` — Tombali
- `bolama/` — Bolama-Bijagós

Do not copy between region folders. Do not treat Cabo Verdean Kabuverdianu as Guinea-Bissau Kriol.
Casamance Kriyol (Senegal) is not stored in these folders.

Sources for a headword must name the region or variety. A form labelled only “Guinea-Bissau Kriol” with no region stays out of the region files until the location is identified.

APiCS Online language 33 (Intumbo, Inverno & Holm 2013) is **Guinea-Bissau Kriyol** at country level. The survey names regional groupings (Cacheu / São Domingos; Bissau / Bolama; Bafatá / Geba), but the examples and italic lexicon are not labelled for a single region. Those forms are **not** copied into any region folder, and they are **not** stored as a merged lexicon in this parent index.

APiCS 34 is Casamancese Creole (Ziguinchor, Senegal). It is not Guinea-Bissau evidence.

Survey: https://apics-online.info/surveys/33. Structure dataset: https://apics-online.info/contributions/33. License: CC BY 4.0. The country-level recording was not copied into a region folder.

## Missing-term protocol

Use the `TERM_NOT_FOUND` object in the region folder that was queried. Do not fall back to another region.
