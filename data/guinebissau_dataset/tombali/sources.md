# Kriol of Tombali sources

This dataset documents **Kriol of Tombali** only (Região de Tombali).

Translation pairs: Kriol of Tombali → Portuguese, Kriol of Tombali → English.

Do not fill missing entries from other Guinea-Bissau region folders.
Do not treat Cabo Verdean Kabuverdianu or Casamance Kriyol as this variety.

## Sources used in this folder

None yet. Add attested forms only from sources that name the Tombali variety or this region.

APiCS Online language 33 is country-level Guinea-Bissau Kriyol. It is not labelled as this region and is not used here. See `data/guinebissau_dataset/sources.md`.

Priority sources to search when collecting (do not invent forms from this list):

- APiCS Online, when the example is labelled as Kriol of Tombali / this region
- Published Kriol dictionaries and grammars that locate the form in Tombali
- Institutional orthography documents, only when they give a lemma labelled for Tombali

## Not used as Tombali evidence

- Other folders under `data/guinebissau_dataset/`
- `data/caboverde_dataset/`
- Casamance Kriyol of Senegal
- `data/saotome_dataset/forro/`, `data/saotome_dataset/angolar/`, `data/saotome_dataset/lungie/`
- Portuguese of Guinea-Bissau
