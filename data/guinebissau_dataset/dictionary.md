# Guinea-Bissau Kriol

**ISO 639-3:** pov  
**Project started:** 23 March 2023  
**Collection started:** 23 April 2025  
**Time since project start:** 2 years 1 month  

Kriol / Kiriol / Guineense is not one lexicon in this repository. Each region has its own folder.

Do not copy a form from one region into another. Do not copy Cabo Verdean Kabuverdianu, Casamance Kriyol, Forro, Angolar, or Lung’Ie.

This parent folder is an **index**, not a merged dictionary.
