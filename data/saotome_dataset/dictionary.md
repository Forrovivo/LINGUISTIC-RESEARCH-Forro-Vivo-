# São Tomé and Príncipe

**Project started:** 23 March 2023  

Country folder for the indigenous Portuguese-lexifier creoles of São Tomé and Príncipe.

Do not copy a form from one language into another. Do not copy Cabo Verdean Kabuverdianu or Guinea-Bissau Kriol.

This parent folder is an **index**, not a merged dictionary.

Angolar / Ngola is a São Tomé language. Angola Contruy is documented in `data/angola_dataset/contruy/`. They are not the same language. Do not copy between them.

If a term is not attested for that language, return `TERM_NOT_FOUND` for that language only.
