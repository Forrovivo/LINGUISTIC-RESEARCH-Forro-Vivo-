# Seychellois sources

This dataset documents **Seychellois** only.

Seychellois collection starts on **20 August 2026** (**3 years 4 months 28 days** after the project start of **23 March 2023**). The lexicon stays empty until a cited source names Seychellois.

Do not copy Mauritian, Réunion Creole, Forro, Kabuverdianu, or Guinea-Bissau Kriol.

## Sources used in this folder

None yet. Add attested forms only from sources that name Seychellois.

## Not used as Seychellois evidence

- Other folders under `data/seychelles_dataset/`
- Other country folders in `data/`
- Portuguese, English, or French of Seychelles unless a source labels the form as Seychellois

## Missing-term protocol

Use this folder’s `TERM_NOT_FOUND` object. Do not fall back to another language in this repository.
