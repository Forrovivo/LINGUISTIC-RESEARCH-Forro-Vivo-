# Ghanaian Pidgin sources

This dataset documents **Ghanaian Pidgin** only.

Ghanaian Pidgin collection starts on **20 August 2026** (**3 years 4 months 28 days** after the project start of **23 March 2023**). The lexicon stays empty until a cited source names Ghanaian Pidgin.

Do not copy Naija, Krio, Pichi, or Cameroonian Pidgin.

## Sources used in this folder

None yet. Add attested forms only from sources that name Ghanaian Pidgin.

## Not used as Ghanaian Pidgin evidence

- Other folders under `data/ghana_dataset/`
- Other country folders in `data/`
- Portuguese, English, or French of Ghana unless a source labels the form as Ghanaian Pidgin

## Missing-term protocol

Use this folder’s `TERM_NOT_FOUND` object. Do not fall back to another language in this repository.
