# Angola creole (alias)

**Canonical dataset:** [../saotome/angolar/](../saotome/angolar/)
**Project started:** 23 March 2023  
**Angola folder work started:** 23 April 2025  
**Time since project start:** 2 years 1 month  

In this repository the **principal Angola-related creole is Angolar / Ngola**.

Do not add a second lexicon in this folder. Look up and store Angolar headwords in:

- [../saotome/angolar/dictionary.md](../saotome/angolar/dictionary.md)
- [../saotome/angolar/dictionary.json](../saotome/angolar/dictionary.json)
- [../saotome/angolar/sources.md](../saotome/angolar/sources.md)
- [../saotome/angolar/Audio/](../saotome/angolar/Audio/)

Sources locate Angolar on São Tomé. The autonym *Ngola* and the community name Angolares refer to Angola.
