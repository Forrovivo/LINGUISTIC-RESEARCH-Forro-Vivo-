# Naija sources

This dataset documents **Naija** only.

Naija collection starts on **20 August 2026** (**3 years 4 months 28 days** after the project start of **23 March 2023**). The lexicon stays empty until a cited source names Naija.

Do not copy Ghanaian Pidgin, Krio, Pichi, or Cameroonian Pidgin.

## Sources used in this folder

None yet. Add attested forms only from sources that name Naija.

## Not used as Naija evidence

- Other folders under `data/nigeria_dataset/`
- Other country folders in `data/`
- Portuguese, English, or French of Nigeria unless a source labels the form as Naija

## Missing-term protocol

Use this folder’s `TERM_NOT_FOUND` object. Do not fall back to another language in this repository.
