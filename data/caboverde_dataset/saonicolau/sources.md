# Kabuverdianu of São Nicolau sources

This dataset documents **Kabuverdianu of São Nicolau** only (Barlavento).

Translation pairs: Kabuverdianu of São Nicolau → Portuguese, Kabuverdianu of São Nicolau → English.

Do not fill missing entries from other Cabo Verdean island folders.
Do not treat Guinea-Bissau Kriol as this variety.

## Sources used in this folder

### Francisco João Lopes 2012

- **Author:** Francisco João Lopes
- **Year:** 2012
- **Title:** Para uma análise sintática das construções relativas no crioulo da ilha de São Nicolau – Cabo Verde
- **Type:** master’s thesis, Universidade de São Paulo
- **Open URL:** https://doi.org/10.11606/d.8.2012.tde-30102012-095122
- **License:** USP open thesis; cite the author; original terms retained
- **Language documented:** São Nicolau (CSN)
- **What was extracted:** São Nicolau-labelled interrogative and relative markers with a Portuguese gloss
- **Portuguese:** from the thesis gloss
- **English:** null in this pass (the thesis glosses in Portuguese)
- **Not used:** Santiago and São Vicente contrast examples; Cardoso 1989 body (closed book, quoted only when Lopes prints a CSN form)
- **Confidence for cited forms:** high

### Maria de Lurdes Zanoli 2014

- **Author:** Maria de Lurdes Zanoli
- **Year:** 2014
- **Title:** A checagem de 'foco' da categoria 'sujeito' no cabo-verdiano - variedade de São Nicolau
- **Type:** master’s thesis, Universidade de São Paulo
- **Open URL:** https://doi.org/10.11606/d.8.2014.tde-08052015-131322
- **License:** USP open thesis; cite the author; original terms retained
- **Language documented:** São Nicolau
- **What was extracted:** São Nicolau-labelled content words with a Portuguese gloss in the focus and cleft examples
- **Portuguese:** from the thesis gloss
- **English:** null in this pass (the thesis glosses in Portuguese)
- **Not used:** São Vicente contrast examples in the same thesis; Cardoso 1989 body (closed book)
- **Confidence for cited forms:** high
