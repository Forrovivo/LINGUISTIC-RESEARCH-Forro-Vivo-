# Kabuverdianu of São Nicolau dictionary

**Language:** Kabuverdianu of São Nicolau  
**Island:** São Nicolau  
**Group:** Barlavento  
**ISO 639-3:** kea  
**Translation pairs:** Kabuverdianu of São Nicolau → Portuguese; Kabuverdianu of São Nicolau → English
**Project started:** 23 March 2023  

This file is a **São Nicolau-only** Cabo Verdean Creole dataset. It is not a website and not an application.

Do not copy headwords from other Cabo Verdean island folders (santiago, fogo, maio, brava, saovicente, santoantao, sal, boavista).
Do not copy Guinea-Bissau Kriol, Forro, Angolar, or Lung’Ie.

Entries were isolated from São Nicolau-labelled (CSN) forms in Francisco João Lopes 2012. Santiago and São Vicente contrast examples were not copied. Portuguese word glosses follow that thesis. English is null when the source does not print it.

Further São Nicolau-labelled lemmas were isolated from Zanoli 2014. São Vicente contrast examples were not copied.

No lexicon has been copied from other folders. Add a headword only when a cited source labels it as the creole of São Nicolau.
