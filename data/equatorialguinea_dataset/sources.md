# Equatorial Guinea sources

This parent folder is an **index of Equatorial Guinea languages**. It does not hold a merged word list.

Equatorial Guinea collection starts on **20 August 2026** (**3 years 4 months 28 days** after the project start of **23 March 2023**).

Each language is isolated:

- `annobonese/` — Annobonese (`fab`)
- `pichi/` — Pichi (`fpe`)

Do not copy between these folders. Do not copy another country folder into this index.

## Missing-term protocol

Query a named language folder. Use that folder’s `TERM_NOT_FOUND` object. Do not fall back to another language in this repository.
