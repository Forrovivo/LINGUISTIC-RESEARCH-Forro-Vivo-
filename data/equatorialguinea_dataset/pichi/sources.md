# Pichi sources

This dataset documents **Pichi** only.

Pichi collection starts on **20 August 2026** (**3 years 4 months 28 days** after the project start of **23 March 2023**). The lexicon stays empty until a cited source names Pichi.

Do not copy Krio, Naija, Ghanaian Pidgin, Cameroonian Pidgin, or Annobonese.

## Sources used in this folder

None yet. Add attested forms only from sources that name Pichi.

## Not used as Pichi evidence

- Other folders under `data/equatorialguinea_dataset/`
- Other country folders in `data/`
- Portuguese, English, or French of Equatorial Guinea unless a source labels the form as Pichi

## Missing-term protocol

Use this folder’s `TERM_NOT_FOUND` object. Do not fall back to another language in this repository.
