# Equatorial Guinea

**Country:** Equatorial Guinea  
**Project started:** 23 March 2023  
**Collection started:** 20 August 2026  
**Time since project start:** 3 years 4 months 28 days  

Equatorial Guinea is not one lexicon in this repository. Each language has its own folder.

This parent folder is an **index**, not a merged dictionary.

## Languages

| Language | ISO | Path |
|---|---|---|
| Annobonese | `fab` | [annobonese/](annobonese/) |
| Pichi | `fpe` | [pichi/](pichi/) |

Each language folder has `dictionary.md`, `dictionary.json`, and `sources.md`. Lexicons stay empty until a source names that language.

Do not store a merged Equatorial Guinea lexicon here. Annobonese and Pichi are separate datasets under this folder. Do not copy between them. Annobonese is not Forro. Pichi is not Krio.

If a term is not attested for that language, return `TERM_NOT_FOUND` for that language only.
