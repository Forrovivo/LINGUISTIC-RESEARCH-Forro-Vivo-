# Annobonese sources

This dataset documents **Annobonese** only.

Annobonese collection starts on **20 August 2026** (**3 years 4 months 28 days** after the project start of **23 March 2023**). The lexicon stays empty until a cited source names Annobonese.

Do not copy Forro, Angolar, Lung’Ie, Pichi, or Portuguese of Equatorial Guinea.

## Sources used in this folder

None yet. Add attested forms only from sources that name Annobonese.

## Not used as Annobonese evidence

- Other folders under `data/equatorialguinea_dataset/`
- Other country folders in `data/`
- Portuguese, English, or French of Equatorial Guinea unless a source labels the form as Annobonese

## Missing-term protocol

Use this folder’s `TERM_NOT_FOUND` object. Do not fall back to another language in this repository.
