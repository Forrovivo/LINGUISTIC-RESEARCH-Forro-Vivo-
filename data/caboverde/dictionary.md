# Cabo Verdean Creole

**ISO 639-3:** kea  
**Project started:** 23 March 2023  
**Collection started:** 23 April 2025  
**Time since project start:** 2 years 1 month  

Kabuverdianu / Kriolu is not one lexicon in this repository. Each inhabited island has its own folder.

Do not copy a form from one island into another. Do not copy Guinea-Bissau Kriol, Forro, Angolar, or Lung’Ie.

This parent folder is an **index**, not a merged dictionary.

Each island folder has `dictionary.md`, `dictionary.json`, and `sources.md`. Santiago, Brava, and São Vicente hold APiCS-labelled lexicons for those islands only. The other inhabited-island folders stay empty until a source names that variety.

If a term is not attested for that island, return `TERM_NOT_FOUND` for that island only.
