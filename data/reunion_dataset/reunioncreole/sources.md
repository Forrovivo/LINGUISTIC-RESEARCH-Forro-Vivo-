# Réunion Creole sources

This dataset documents **Réunion Creole** only.

Réunion Creole collection starts on **20 August 2026** (**3 years 4 months 28 days** after the project start of **23 March 2023**). The lexicon stays empty until a cited source names Réunion Creole.

Do not copy Mauritian, Seychellois, or French of Réunion.

## Sources used in this folder

None yet. Add attested forms only from sources that name Réunion Creole.

## Not used as Réunion Creole evidence

- Other folders under `data/reunion_dataset/`
- Other country folders in `data/`
- Portuguese, English, or French of Réunion unless a source labels the form as Réunion Creole

## Missing-term protocol

Use this folder’s `TERM_NOT_FOUND` object. Do not fall back to another language in this repository.
