# Sango sources

This dataset documents **Sango** only.

Sango collection starts on **20 August 2026** (**3 years 4 months 28 days** after the project start of **23 March 2023**). The lexicon stays empty until a cited source names Sango.

Do not copy Kituba, Fanakalo, or French of the Central African Republic.

## Sources used in this folder

None yet. Add attested forms only from sources that name Sango.

## Not used as Sango evidence

- Other folders under `data/centralafrican_dataset/`
- Other country folders in `data/`
- Portuguese, English, or French of Central African Republic unless a source labels the form as Sango

## Missing-term protocol

Use this folder’s `TERM_NOT_FOUND` object. Do not fall back to another language in this repository.
