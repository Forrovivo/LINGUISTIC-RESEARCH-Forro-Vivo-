# Sources

**Project started:** 23 March 2023

Every form, gloss, example, pronunciation, and cultural note in this repository must come from a cited source. Folder-level `sources.md` files are the record of **what was extracted where**. This file is the repository index and shared bibliography.

Collection rules: [METHODOLOGY.md](METHODOLOGY.md). How to add entries: [CONTRIBUTING.md](CONTRIBUTING.md).

Wikipedia, social media, unsourced word lists, and generated text are not accepted as the only evidence for an entry. They may be used only to locate a citable work.

## Priority order

1. **Provided files** in this repository (PDF, TXT, Markdown, CSV, JSON, dictionaries, academic publications).
2. **Academic and institutional sources** (university publications, published dictionaries, ALUSTP, ALUPEC, language documentation).
3. **Reliable linguistic websites**, never as the sole verification for an important claim.

A source must name the language, island, or region before a form is stored in that folder.

## Published works

### São Tomé and Príncipe

- Araujo, Gabriel Antunes de; Hagemeijer, Tjerk. 2013. *Dicionário livre santome/português — Livlu-nglandji santome/putugêji*. São Paulo: Hedra. **CC BY-NC**. Forro / Santome only.
- Rougé, Jean-Louis; Schang, Emmanuel. 2012. Histoire des créoles et génétique: le cas de l’angolar. *Sciences et Techniques du Langage* 9. Use only the column labelled for the language being stored.
- Hagemeijer, Tjerk. 2013. APiCS survey: Santome. <https://apics-online.info/surveys/35>
- Maurer, Philippe. 2013. APiCS survey: Angolar. <https://apics-online.info/surveys/36>
- Maurer, Philippe. 2013. APiCS survey: Principense. <https://apics-online.info/surveys/37>
- ALUSTP. 2010. Unified orthography proposal for Santome, Angolar, and Lung’Ie.
- Bandeira, Manuele. 2017. *Reconstrução fonológica e lexical do protocrioulo do Golfo da Guiné*. Tese de doutorado, Universidade de São Paulo. <https://doi.org/10.11606/t.8.2017.tde-05042017-134159>. Use only the column for the language being stored. Do not store reconstructed protoforms as headwords.
- Bandeira, Manuele; Agostinho, Ana Lívia; Freitas, Shirley. 2021. Phonetic-phonological aspects of modern Angolar. *Alfa* 65, e13177. <https://doi.org/10.1590/1981-5794-e13177>. **CC BY 4.0**. Use only the labelled language column.
- Araujo, Vanessa Pinheiro de. 2013. *Um dicionário principense-português*. Dissertação de mestrado, Universidade de São Paulo. <https://doi.org/10.11606/d.8.2013.tde-11062013-101052>. Lung’Ie only.
- Agostinho, Ana Lívia; Araujo, Gabriel Antunes de. 2021. *Lung’Ie, lunge no: método para aprender lung’Ie*. São Paulo: FFLCH/USP. <https://doi.org/10.11606/9786587621500>. **CC BY-NC-SA 4.0**. Lung’Ie–Portuguese glossary only.
- Balduino, Amanda Macedo; Agostinho, Ana Lívia; Araujo, Gabriel Antunes de. Processos de nasalização em lung’Ie. *Alfa*. <https://www.scielo.br/j/alfa/a/zJ4wnTYQXtM4RMsVLS9qMPC/>. Lung’Ie phonetic examples as printed.

### Cabo Verde

- Lang, Jürgen. 2013. APiCS survey: Cape Verdean Creole of Santiago. <https://apics-online.info/surveys/30>. Santiago folder only.
- Baptista, Marlyse. 2013. APiCS survey: Cape Verdean Creole of Brava. <https://apics-online.info/surveys/31>. Brava folder only.
- Swolkien, Dominika. 2013. APiCS survey: Cape Verdean Creole of São Vicente. <https://apics-online.info/surveys/32>. São Vicente folder only.

APiCS has no separate language for Fogo, Maio, Santo Antão, São Nicolau, Sal, or Boa Vista. Do not copy Santiago, Brava, or São Vicente extracts into those folders. ALUPEC and other island-labelled works may be used when they name the island.

### Guinea-Bissau

- Intumbo, Incanha; Inverno, Liliana; Holm, John. 2013. APiCS survey: Guinea-Bissau Kriyol. <https://apics-online.info/surveys/33>. Country-level. **Not** copied into a region folder and **not** stored as a merged lexicon in the parent index.

APiCS Casamancese Creole (Ziguinchor, Senegal) is not Guinea-Bissau evidence.

### Shared APiCS edition

- Michaelis, Susanne Maria; Maurer, Philippe; Haspelmath, Martin; Huber, Magnus (eds.). 2013. *Atlas of Pidgin and Creole Language Structures Online*. Leipzig: Max Planck Institute for Evolutionary Anthropology. <https://apics-online.info/>. **CC BY 4.0**.

Copied audio stays in the matching language folder (`dictionary/saotome/forro/Audio/`, `dictionary/saotome/angolar/Audio/`, `dictionary/saotome/lungie/Audio/`, and the Cabo Verde island `Audio/` folders that hold recordings). A glossed-text recording is not a citation form for every word.

## Local extracts

Primary local files used for São Tomé collection:

- `Dicionario livre santome.txt` — Araujo & Hagemeijer 2013 (Forro)
- `Forro lan.txt` — Rougé & Schang 2012 (use only the labelled language)

PDFs under `_source_pdfs/` are source documents for extraction. They are not a second lexicon.

## What is not a source for a headword

- Another creole folder in this repository
- Portuguese of São Tomé, Cabo Verde, Guinea-Bissau, or Angola
- Kimbundu, Umbundu, or Angolan Portuguese stored as Angolar
- An unnamed “Cape Verdean” or “Guinea-Bissau Kriol” form
- Casamance Kriyol of Senegal
- Application code
